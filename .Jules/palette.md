## 2024-10-13 - Missing aria-labels on bare icon close buttons
**Learning:** The application extensively uses `lucide-react` icons inside empty `<button>` containers for generic interactions (e.g., "Close", "Skip"). Since these buttons have neither text content nor an `aria-label`, they create accessibility barriers (WCAG 2.1 SC 4.1.2 Name, Role, Value) where screen readers will simply read out "button" without context. This pattern was identified in several key overlays, including `TransactionDetailModal`, `PageGuide`, and `OnboardingTour`.
**Action:** When implementing or reviewing icon-only interactive elements, explicitly verify that an `aria-label` or visually hidden text is provided. Automated regex scanning (e.g., `/<button[^>]*>\s*<[A-Za-z]+Icon[^>]*>\s*<\/button>/`) can proactively catch these common accessibility regressions.
