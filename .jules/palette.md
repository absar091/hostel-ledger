## 2024-05-18 - Replacing Native Tooltips with Radix UI Tooltip Component
**Learning:** When trying to replace native `title` HTML attributes with the design system's `<Tooltip>` component, always make sure that the components from `@radix-ui/react-tooltip` or `@/components/ui/tooltip` are already present in the codebase. If the `import` fails to resolve, the page crashes (white screen of death). Additionally, when conditionally rendering the `TooltipContent` (e.g. only when a sidebar is collapsed), the parent tree must be correctly wrapped with a `<TooltipProvider>`. Setting `delayDuration={0}` on the provider removes the lag in showing the tooltip. Also, make sure to resolve `eslint` typing correctly, such as specifying `{ id: string, icon: React.ElementType, label: string, path: string, badge?: number }` instead of using `any` when iterating over navItems.
**Action:** Before running tool replacements, verify `Tooltip` component exists via `read_file`. Wrap the affected block inside `<TooltipProvider delayDuration={0}>` and only conditionally render `<TooltipContent>`. And use specific types instead of `any` for iterators.
