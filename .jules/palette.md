## 2024-03-24 - Interactive Item Focus State Isolation
**Learning:** Complex interactive elements like the `TransactionItem` card use an outer interactive `button` and inner utility buttons (like the Discuss chat). Keyboard accessibility requires explicit visual focus boundaries (`focus-visible`) on both layers. Relying solely on outer hover/active states leaves keyboard users unaware of their focus target, and inner buttons need explicit `aria-label` overriding a visual `title` tooltip for screen readers.
**Action:** When designing cards or list items with nested interactive buttons, explicitly apply `focus-visible:ring-2 focus-visible:ring-ring` independently to the outer card element and any inner utility buttons. Ensure nested buttons duplicate visual `title` texts into `aria-label`s for screen reader clarity.
