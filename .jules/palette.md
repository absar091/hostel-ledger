## 2025-04-06 - Replacing Native Title Attributes with Radix Tooltips
**Learning:** Native `title` attributes on interactive elements provide a delayed, inconsistently styled, and poorly accessible tooltip experience. When integrating Radix UI tooltips, it's critical to explicitly remove the native `title` attribute to prevent a "double-tooltip" effect where both the custom and native tooltips appear simultaneously, confusing users and screen readers. Additionally, tooltips must be globally wrapped in `<TooltipProvider>` to prevent application crashes due to missing context.
**Action:** Always replace native `title` attributes on icon-only buttons with Radix `<Tooltip>` components, ensuring the native attribute is removed. Use `<TooltipTrigger asChild>` to prevent invalid HTML nesting, and wrap the component tree with `<TooltipProvider>`. Utilize `useTranslation` for the tooltip and `aria-label` content.
## 2025-04-06 - Fixing Tooltip Missing Labels in Modal
**Learning:** Native `title` attributes on interactive elements provide a delayed, inconsistently styled, and poorly accessible tooltip experience. Always replace native `title` attributes on icon-only buttons with Radix `<Tooltip>` components, ensuring the native attribute is removed. Ensure you also add semantic `aria-label` tags for screen reader support. When adding Radix UI `<TooltipContent>` inside a component with a high z-index (e.g., a modal with `z-[100]`), explicitly provide a higher z-index class to the TooltipContent (e.g., `className="z-[110]"`) to prevent the tooltip from being hidden behind the parent container. Use `<TooltipTrigger asChild>` to prevent invalid HTML nesting, and wrap the component tree with `<TooltipProvider>`.
**Action:** Replace `title` strings with `<TooltipProvider>`, `<Tooltip>`, `<TooltipTrigger asChild>`, and `<TooltipContent>` blocks when making accessibility fixes to buttons. Make sure to apply `aria-label` tags and provide appropriate custom `z-index` classes to Tooltip elements inside modals or portals. Also, use temporary scripts for these modifications but ensure they are cleaned up and not committed to the codebase.
