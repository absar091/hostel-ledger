## 2025-04-06 - Replacing Native Title Attributes with Radix Tooltips
**Learning:** Native `title` attributes on interactive elements provide a delayed, inconsistently styled, and poorly accessible tooltip experience. When integrating Radix UI tooltips, it's critical to explicitly remove the native `title` attribute to prevent a "double-tooltip" effect where both the custom and native tooltips appear simultaneously, confusing users and screen readers. Additionally, tooltips must be globally wrapped in `<TooltipProvider>` to prevent application crashes due to missing context.
**Action:** Always replace native `title` attributes on icon-only buttons with Radix `<Tooltip>` components, ensuring the native attribute is removed. Use `<TooltipTrigger asChild>` to prevent invalid HTML nesting, and wrap the component tree with `<TooltipProvider>`. Utilize `useTranslation` for the tooltip and `aria-label` content.

## 2025-05-15 - Enhancing Interactive Elements with Tooltips
**Learning:** We replaced native `title` attributes with Radix Tooltips on `TransactionDetailModal.tsx`, `Sidebar.tsx`, `CreateGroupSheet.tsx` and `sidebar.tsx` which improved UX and accessibility significantly. We encountered issues ensuring `TooltipProvider` was wrapping elements and that tooltips were structured semantically correctly. We noticed the existing tooltips on these elements lacked clear `aria-label` alternatives for users relying on assistive technology and `title` tags cause double tooltips or poorly styled default OS tooltips.
**Action:** Replace `title` tags on interactive elements such as buttons and divs with Radix Tooltip components `<Tooltip>`, `<TooltipTrigger asChild>` and `<TooltipContent>`.  Add `aria-label` to the element inside `<TooltipTrigger>` to ensure accessibility for screen readers. Remove the `title` attribute from the element. Wrap the structure in `<TooltipProvider>` for safe rendering.
