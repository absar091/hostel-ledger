## 2024-05-15 - Radix UI Tooltip implementation
**Learning:** Native `title` attributes on buttons are bad for accessibility as they don't respond to keyboard focus and have styling limitations. Radix UI Tooltips solve this but have specific rendering requirements in this repo.
**Action:** When replacing native `title` attributes with Tooltips on action buttons, ensure you use `Tooltip, TooltipTrigger, TooltipContent, TooltipProvider`. Remove the native `title` attribute, but **MUST ADD an `aria-label`** on the trigger to preserve the accessible name, especially for icon-only buttons. The TooltipTrigger must wrap the button with `asChild`. TooltipContent shouldn't be conditionally mounted to avoid React reconciliation issues; instead, conditionally render the inner content or don't wrap the item if it shouldn't show.
