## 2024-10-19 - Radix UI Tooltip implementation for icon-only components
**Learning:** When using Radix UI `Tooltip` components instead of native browser `title` attributes on icon-only buttons (like a collapsed sidebar), conditional rendering of the `Tooltip` and `TooltipContent` provides much better visual feedback and accessibility. Removing the native `title` attribute is necessary to avoid double tooltips. Remember to move the React `key` prop to the outermost returned element when wrapping buttons inside `.map()` arrays.
**Action:** Always prefer design-system tooltips over native `title` attributes for primary navigation or common icon buttons to ensure immediate, styled feedback, and ensure `key` props are placed on the outermost wrapper element like `React.Fragment`.
