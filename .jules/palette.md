## 2023-10-01 - Replaced Tooltips in Sidebar
**Learning:** Replaced the native `title` attribute on interactive elements (sidebar icons) with the Radix UI `<Tooltip>` components for better UX and consistency. When replacing title elements wrapped in logical `&&` operations, it's vital to make sure the tooltip trigger correctly passes down its ref by using `asChild`. Furthermore, it's crucial to permanently apply the tooltip wrapper rather than conditionally applying the wrapper to prevent the component from unmounting and disrupting user focus.
**Action:** When working on tooltips for interactive components, wrap elements statically to avoid re-mounting and use `TooltipContent` rendering conditionally to maintain stability.
