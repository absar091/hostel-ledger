## 2025-02-28 - Tooltips in Collapsible Sidebars
**Learning:** When sidebars collapse to icon-only buttons, applying Tooltips improves accessibility and UX. However, leaving the Tooltip component in the React tree when the sidebar is expanded can lead to awkward behaviors or invalid HTML if not carefully conditionalized.
**Action:** When conditionally displaying Radix UI tooltips (e.g., showing a tooltip only when a sidebar is collapsed), conditionally render the entire `<TooltipProvider><Tooltip>` component tree rather than leaving an always-present `<Tooltip>` with conditionally rendered `<TooltipContent>`. Ensure you wrap the element properly without breaking existing functionality.
