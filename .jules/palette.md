## 2024-05-18 - Tooltips for icon-only buttons in Admin Dashboard
**Learning:** Found several icon-only action buttons in the Admin Dashboard without accessible labels but utilizing native `title` attributes. Replacing these with Radix UI Tooltips and setting `focus-visible` ensures robust accessibility (including screen readers) while offering a visually consistent layout without tooltip overlap.
**Action:** When working with admin views that contain dense icon button groups, always upgrade native tooltips to Radix UI ones accompanied by `aria-label` attributes to enforce keyboard accessibility via `focus-visible`.
