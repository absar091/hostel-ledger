## 2025-04-06 - Replacing Native Title Attributes with Radix Tooltips
**Learning:** Native `title` attributes on interactive elements provide a delayed, inconsistently styled, and poorly accessible tooltip experience. When integrating Radix UI tooltips, it's critical to explicitly remove the native `title` attribute to prevent a "double-tooltip" effect where both the custom and native tooltips appear simultaneously, confusing users and screen readers. Additionally, tooltips must be globally wrapped in `<TooltipProvider>` to prevent application crashes due to missing context.
**Action:** Always replace native `title` attributes on icon-only buttons with Radix `<Tooltip>` components, ensuring the native attribute is removed. Use `<TooltipTrigger asChild>` to prevent invalid HTML nesting, and wrap the component tree with `<TooltipProvider>`. Utilize `useTranslation` for the tooltip and `aria-label` content.

## 2024-05-20 - Adding Tooltips for Icon-Only Buttons in Navigation
**Learning:** Icon-only buttons used for primary navigation elements often lack proper accessible labels and visual context for users who don't recognize the icon immediately. While `aria-label` provides an accessible name for screen readers, visual users benefit from tooltips explaining the icon's function. The native `title` attribute can cause a double-tooltip effect when combining it with custom components like Radix UI Tooltip. Also, when converting native tooltips on icon-only navigation buttons to a custom tooltip system (e.g., Radix UI), the tooltips must be globally wrapped in `<TooltipProvider>` to prevent application crashes, however, since App.tsx already provides a global TooltipProvider, we don't need a local one unless we need specific delay behavior.
**Action:** When converting native tooltips on icon-only navigation buttons to a custom tooltip system, always ensure you remove the native `title` attribute and maintain the `aria-label` to provide consistent, accessible context for both visual and screen reader users without overlap. Verify TooltipProvider exists globally or add it locally.
