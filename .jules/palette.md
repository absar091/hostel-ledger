## 2024-10-25 - Tooltips and ARIA Labels for Icon-Only Buttons
**Learning:** Replaced standard HTML `title` attributes on icon-only buttons (like "Share", "Close", "Copy" in `TransactionDetailModal.tsx`) with accessible Radix UI `<Tooltip>` components. Leaving the `title` attribute intact alongside the Tooltip creates a double-tooltip effect for screen readers and visual users. Furthermore, relying only on `title` or Tooltips isn't enough; the underlying button still requires an explicit `aria-label` to ensure context is read accurately.
**Action:** When adding custom Tooltips to icon-only buttons, always remove the native `title` attribute, explicitly add an `aria-label` to the button itself, and ensure related Playwright tests are refactored to use `aria-label` selectors instead of `title`.
