## 2023-10-27 - Sidebar Tooltip Accessibility Improvement
**Learning:** The layout sidebar used native `title` attributes on icons and navigation items which are notorious for causing "double-tooltip" effects, inconsistent delay timings, and poor accessibility (they are often not properly read by screen readers if standard attributes are missing or misconfigured). When adding `<TooltipProvider>` to a component like `Sidebar.tsx`, we must be careful with dynamically rendered lists.
**Action:** Replace all native `title` attributes with Radix UI `<Tooltip>` components. Ensure that for lists generated by `.map()`, the React `key` prop is explicitly moved from the inner element to the new outermost `<Tooltip>` wrapper to prevent React rendering errors, and ensure the outer container is wrapped in a `<TooltipProvider>`.
