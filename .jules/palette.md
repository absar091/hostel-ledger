## 2024-05-11 - Custom Tooltips instead of native title attributes
**Learning:** This app frequently relies on the native browser `title` attribute for tooltips (e.g., in icon-only buttons or sidebar items). This is poor UX because it relies on the browser's slow, unstylable tooltip which may not be accessible to all users.
**Action:** When I encounter `title` attributes on interactive elements, I will replace them with Radix UI `<Tooltip>` components, ensuring I use `<TooltipProvider>`, `<Tooltip>`, `<TooltipTrigger asChild>`, and `<TooltipContent>`. For sidebar elements that conditionally show tooltips, I will only conditionally render the `<TooltipContent>` to avoid React reconciliation issues. I must also ensure `aria-label` is set if the tooltip replaces the accessible name of an icon-only element.
