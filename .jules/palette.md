## 2024-06-13 - Mocking Complex UI for Verification
**Learning:** When Playwright verification of complex UI components (like a Sidebar) fails due to authentication walls or complex routing dependencies in a Vite application, injecting a standalone HTML/Tailwind mockup directly into an unauthenticated route using `page.evaluate('document.body.innerHTML = ...')` is an effective workaround to visually verify atomic UI changes like Tooltips without needing to bypass app auth.
**Action:** When testing UI components blocked by auth, start the dev server, navigate to `/login`, and inject a simplified HTML mockup representing the state needed to trigger and verify the specific UI change (e.g., hovering a button to trigger a Tooltip).
