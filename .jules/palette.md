## 2024-05-24 - Custom Tooltips and Accessibility on Icon Buttons
**Learning:** Native `title` attributes on icon-only buttons provide inconsistent experiences across browsers and are poorly supported by screen readers and keyboard navigation. Using a custom accessible tooltip component (like Radix UI's Tooltip) paired with an explicit `aria-label` improves both visual feedback for mouse users and semantic context for assistive technologies.
**Action:** Replace native `title` attributes on icon-only buttons with `<Tooltip>` wrappers and explicitly assign `aria-label`s. Update associated Playwright tests that historically relied on `title` selectors to use the more robust `aria-label` instead.
