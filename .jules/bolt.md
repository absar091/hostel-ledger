## 2026-10-17 - Memoizing Context Values in React Providers\n**Learning:** When creating React Context providers, failing to memoize the `value` object and the functions within it causes all consuming components to re-render whenever the provider's parent re-renders, even if the context state hasn't logically changed. Functional state updates (e.g., `setIsOpen(prev => !prev)`) are critical when using `useCallback` to avoid stale closures without creating dependency chain re-renders.\n**Action:** Always wrap context `value` objects in `useMemo` and functions passed to context in `useCallback` (using functional state updates where possible) to guarantee stable referential equality.
