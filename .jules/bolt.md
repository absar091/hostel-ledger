## 2025-05-18 - Memoizing large context providers requires careful dependencies
**Learning:** When optimizing a large React Context provider (like `FirebaseAuthContext`) with `useMemo`, if the value object contains dozens of functions that are not wrapped in `useCallback` (and thus recreated on every render), including those functions in the `useMemo` dependency array defeats the purpose, as it will re-trigger the memoization on every render. To actually achieve optimization without a massive rewrite to `useCallback` every single function, you can omit the un-memoized functions from the dependency array and suppress the ESLint `react-hooks/exhaustive-deps` warning for that specific `useMemo` block.
**Action:** When memoizing context values containing many inline functions, prioritize stabilizing the value based on the actual primitive/state dependencies, and use `// eslint-disable-next-line react-hooks/exhaustive-deps` inside the returned object (just before the closing bracket of the useMemo value) to bypass the linter safely.
