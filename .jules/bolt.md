## 2024-03-01 - React Context Performance: Single-Pass Iteration over Maps/Entries
**Learning:** In highly trafficked React Context processing functions (like `normalizeMembers` in `FirebaseDataContext.tsx`), chaining multiple array iterations such as `Object.entries(members).map().map()` and performing redundant object cloning operations causes significant overhead and memory allocation spikes due to intermediate array creations. Furthermore, replacing `Array.prototype.map()` with a standard `for` loop in React components can sometimes be an anti-pattern that harms code readability and yields unpredictable runtime micro-optimizations depending on the JavaScript engine.
**Action:** When refactoring mapped array operations in context processors for performance, do not blindly rewrite them into verbose `for` loops. Instead, consolidate the processing logic (object property resolution, conditional checks) into a unified single-pass iteration function that maps directly over the target dataset (using `Array.map` or iterating over keys based on the input type).
