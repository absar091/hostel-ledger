## 2024-06-15 - Memoize SidebarContext value to prevent unnecessary re-renders
**Learning:** Found an opportunity to memoize the value provided by `SidebarContext.Provider` which was previously constructed dynamically on every render. Because the context state and dispatch functions are used by components frequently, providing an unmemoized object reference leads to unnecessary component re-renders. By memoryzing the values and functions using `useMemo` and `useCallback`, we can prevent re-renders, increasing the application's performance. As noted in the memory rules: "target smaller contexts (e.g., SidebarContext) for safe memoization".
**Action:** When creating React contexts that offer both state and modifier functions, ensure that the provided value object is wrapped in `useMemo` and the corresponding modifier functions are wrapped in `useCallback` to retain reference identity and minimize unnecessary DOM reconciliation.
