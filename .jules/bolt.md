## 2024-07-03 - Memoizing Common Context Functions and Components

**Learning:** When widely-used context providers like `FirebaseDataContext` return non-memoized functions (like `getAllTransactions`, `getTransactionsByGroup`), any state update in the context causes these functions to be recreated. This invalidates `useMemo` hooks in consumer components (like `Dashboard` and `Activity`) that depend on these functions, leading to expensive recalculations and unnecessary re-renders of large lists. Additionally, components rendered frequently in lists (like `Avatar` and `TransactionList`) should be wrapped in `React.memo` to prevent re-renders when their parent state changes but their props do not.
**Action:** Wrap context functions returning filtered/processed data in `useCallback` to maintain referential equality across renders. Wrap heavily reused UI components in `React.memo`. Move expensive operations like `.toLowerCase()` outside of `.filter` loops to avoid redundant processing.
