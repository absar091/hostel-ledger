## 2024-05-18 - Sidebar Context Re-render Optimization
**Learning:** Found a missing memoization pattern in the `SidebarContext`. The context value object was being created anew on every render of `SidebarProvider`. Additionally, the toggle functions were re-created on each render, closing over the `isOpen` state, which causes them to change unnecessarily when state changes could be applied functionally (e.g. `setIsOpen(prev => !prev)`). This triggers a re-render for all components that consume `useSidebar()` every time the provider's parent re-renders, even if the sidebar state hasn't changed.
**Action:** Always memoize context values with `useMemo` and functions with `useCallback` (using functional updates where possible) to prevent unnecessary cascading re-renders in context consumers.
