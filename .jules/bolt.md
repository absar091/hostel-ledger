## 2024-05-18 - Memoize filtered collections to prevent O(N) recalculations
**Learning:** Found multiple instances where collections (e.g. `transactions`) were being linearly filtered using `.filter(t => t.type === 'expense')` inside several independent `useMemo` hooks (like `totalSpent`, `expenseCount`, `personalStats`). This causes redundant O(N) array traversals during every render since the filtering itself wasn't strictly memoized as an intermediate step.
**Action:** Always extract the intermediate `.filter()` operation into its own upstream `useMemo` block first (e.g., `const expenseTransactions = useMemo(...)`), then pass that memoized array down as the dependency for downstream hook calculations. Also, always replace nested map-reduce array aggregations like `O(N*M)` inside React render loops with single pass hash-map reductions.
