## 2025-08-07 - React.memo custom equality function pitfalls
**Learning:** When a component wrapped in `React.memo` takes arrays/objects as props and uses a custom `arePropsEqual` function, merely checking array length (`prevProps.payers?.length !== nextProps.payers?.length`) is insufficient and leads to stale UI bugs when inner values (like amounts) update. Also, when extending components with new props (like `id` and `groupId`), they must be added to `arePropsEqual`, otherwise the memoization will completely ignore changes to those props.
**Action:** When auditing React list rendering for performance, check `React.memo` custom equality functions to ensure they deeply compare relevant nested object properties and don't miss newly added props, balancing correctness with comparison speed.
