## 2025-02-28 - Avoid O(N) array mapping in GroupDetail transactions filtering
**Learning:** In React components like GroupDetail, array methods (`filter`, `reduce`) are often chained inside separate `useMemo` hooks (e.g. one for `totalSpent`, one for `expenseCount`). When dealing with frequently changing arrays like `transactions`, this creates multiple O(N) passes through the array, which introduces unnecessary performance overhead and duplicate intermediate arrays.
**Action:** Combine these multiple iteration blocks into a single O(N) `useMemo` block that uses a `for` loop to calculate multiple derived state variables (e.g., `spent`, `count`) in a single pass. Return an object containing all derived state from the hook, and ensure downstream hooks properly destructure and list these values in their dependency arrays.
