## 2024-05-19 - Missing useCallback for provider functions
**Learning:** Context provider functions like `getTransactionsByGroup`, `getTransactionsByMember` and `getAllTransactions` are exported through `FirebaseDataContext`. If they are not wrapped in `useCallback`, they are recreated on every render of the provider, which in turn causes the context value object to be recreated. This triggers a cascading re-render for all components that consume the context using `useFirebaseData()`, even if the actual data (`transactions`, `groups`) hasn't changed.
**Action:** Always wrap context provider functions in `useCallback` when they are returned as part of the context value, and include them in the dependency array of the context `value` memoization if needed (or if the `value` is memoized, omitting them from the context `value` dependency array is wrong and causes stale closures or ESLint warnings).
